# Mine Duel

Arkadaşlarınla sıra tabanlı, ortak mayın tarlası düellosu. Tarayıcıda çalışır; kurulum ve hesap gerekmez.

**▶ Oyna: https://safaktanik.github.io/**

- 2–4 kişilik masalar, 6 mod (Son Kalan, Yıldırım, Mayın Avcısı, Bölge Savaşı, Hazine Avı, Zincir)
- Arkadaşlarla oyna: biri oda kurar, diğerleri 5 haneli kodla ya da davet linkiyle katılır (telefonlar birbirine doğrudan bağlanır)
- Botlarla antrenman, sonar, kalkan, bonus kutuları, ipucu feneri, madalyalar
- iPhone'da Safari → Paylaş → "Ana Ekrana Ekle" ile uygulama gibi açılır

Bu depo yalnızca yayındaki sürümü içerir (`index.html` tek dosyadır). Oyun içindeki **💌 Görüşünü yaz** ile hata ve önerilerini gönderebilirsin.
