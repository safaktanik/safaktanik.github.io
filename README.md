# Mine Duel

Okey usulü masalarda 2–4 kişilik, sıra tabanlı ortak mayın tarlası düellosu. Tarayıcıda çalışır; kurulum ve hesap gerekmez.

**▶ Oyna: https://safaktanik.github.io/**

- 7 mod: Son Kalan, Yıldırım, Mayın Avcısı, Bölge Savaşı, Hazine Avı, Zincir, Daralan Tahta
- Botlu masalar, arkadaşlarla oyna (5 haneli kod ya da davet linki), Günün Bulmacası, görevler, tahta temaları
- Güçler: Sonar, Pas, Zorla (Mayın Avcısı'nda İmha); kalkan ve bonus kutuları
- Telefona uygulama gibi kurulur; bir kez açıldıktan sonra internetsiz de başlar (çevrimdışı botlu masalar, bulmaca)

Bu depo yalnızca yayındaki sürümü içerir (`index.html` tek dosyadır). `yeni/` eski davet linklerini ve kısayolları ana sayfaya yönlendirir.
